📧 Email Reminder Setup

Add these variables to your .env file to receive email notifications when reminders fire:

SMTP_HOST=smtp.gmail.com SMTP_PORT=587 SMTP_USER=you@gmail.com SMTP_PASSWORD=your_app_password SMTP_FROM=you@gmail.com NOTIFY_EMAIL=you@example.com

For Gmail, use an App Password (not your main password). Restart the server after editing .env.
